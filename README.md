Deskie is a custom 3D-printed modular desk organiser to make space for my messy desk, and allow me to focus again!

## What is is
Deskie is a modular desk organiser designed and modelled in Fusion 360, then 3D printed to help keep my workspace neat and organised. Its modular design allows different parts to be arranged to suit my desk setup and storage needs! 
The project focuses on 3D modelling, designing functional parts, and turning a digital design into a physical object through 3D printing.

## Why?
This project was created as part of Hack Club's [Half Life](https://halflife.hackclub.com/) Week 2 project on CAD. It is my first time using any 3D modelling software / CAD! 
Instead of following the beginner tutorial this time, I decided to challenge myself by coming up with something custom and designing it from scratch.
I wanted to make something practical that I could actually use on my desk while learning more about CAD, modular design, and 3D printing along the way :)

## Project Status
The 3D models have been designed in Fusion 360 and are intended for 3D printing. The project is focused on creating a functional, modular desk organiser.
Further improvements and customisations may happen as I continue experimenting with the design :)

## Software 
- Fusion 360 - Used to create and model the desk organiser and its modular components
